# Héroes — V3

> Los **44 héroes jugables**: las 4 clases de cada una de las [11 razas](../razas/). Este documento es su **catálogo de fichas**, no el de razas.

**Qué campos lleva un héroe está en [La ficha](../sistemas/ficha.md)**, que es donde se define para las 132: un héroe lleva lo mismo que una unidad **menos el tier**, y nada más — ni rango, ni nivel, ni progresión. Aquí van sus valores.

**La asignación de Características está cerrada, las 44.** Lo que falta son los **valores numéricos** de las 8 Habilidades *(insumo pendiente)* y el trasfondo de cada uno.
